# AstraNotes-Tracks (星律官方曲库)

这里是次世代乐队节奏动作游戏 **AstraNotes (星律)** 的官方乐曲与谱面资源仓库。

---

## 🎮 游戏客户端下载

请前往 AstraNotes 官方主仓库获取最新版客户端（支持 Windows 与 Android 双端）：

👉 **[https://github.com/xingstardog/AstraNotes](https://github.com/xingstardog/AstraNotes)**

---

## 🎵 乐曲资源下载说明

- 本仓库所有官方曲目包发布于 [Releases](https://github.com/xingstardog/AstraNotes-Tracks/releases)。
- AstraNotes 游戏客户端内置“曲库下载中心”，可自动从本仓库一键下载并解压游玩。
- 亦可手动下载对应曲目 `.zip`，解压到游戏根目录下的 `Tracks/` 文件夹中即可立即游玩。

### 📦 曲目清单索引
本仓库根目录下的 [`catalog_online.json`](catalog_online.json) 包含全量 89 首官方曲目的元数据、高潮试听区间与 Release 下载直链。
